# Responsible AI boundaries

- This is a care-information and coordination prototype, not a medical device or diagnostic service.
- Use synthetic data in the demo.
- Never invent medicine names, doses, schedules, diagnoses, or interactions.
- If source information is absent or ambiguous, say it cannot be verified and direct the user to a caregiver or qualified professional.
- For potentially urgent symptoms, direct the user to appropriate emergency medical help.
- No external messages, HR actions, or data sharing without explicit user confirmation and a tested integration.
- Never commit API keys, tokens, or private records.
